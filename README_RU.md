# PinGraph

[English README](README.md) | [Русский README](README_RU.md)

Минималистичный локальный клиент и реконструктор графа рекомендаций для Pinterest. Извлекает алгоритмические опорные узлы, упаковывает их в защищенные криптографические токен-строки (`vp1_`) и рендерит чистую сетку без рекламы с бесконечным скроллом и зум-лайтбоксом.

## Возможности

* **Антирекламный фильтр:** Автоматически отсекает спонсорские креативы, рекламные карусели и коммерческие блоки на основе структурной валидации ID.
* **Шифрование токенов (`vp1_`):** Безопасно упаковывайте и делитесь своими рекомендациями, не передавая приватные ключи или сессии (используется SHA256-CTR и HMAC-SHA256).
* **Замороженная сетка:** Сбалансированная четырехколоночная верстка предотвращает смещение элементов при подгрузке новых волн.
* **Локальный лайтбокс с зумом:** Встроенный просмотрщик изображений в высоком разрешении с поддержкой масштабирования колесиком мыши и перетаскивания.
* **Автозахват сессии:** Автоматически считывает локальные куки браузера для воспроизведения персональной ленты рекомендаций в один клик.

## Установка и запуск

1. Клонируйте репозиторий и скачайте библиотеку:
```bash
   git clone https://github.com/ollxel/pin-graph.git
   cd pingraph
   pip install browser_cookie3
```
2. Запустите скрипт:
```Bash
    python3 main.py
```
3. Откройте в браузере:
`http://localhost:8080`
